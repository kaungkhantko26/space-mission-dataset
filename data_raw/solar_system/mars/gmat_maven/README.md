\# GMAT-Generated MAVEN Mars Orbit Dataset



\## 1. Overview



This dataset contains simulated MAVEN spacecraft position and velocity data generated using NASA's General Mission Analysis Tool (GMAT).



The simulation is based on GMAT's `Ex\_MarsBPlane` sample mission, which demonstrates an Earth-to-Mars interplanetary trajectory, Mars B-plane targeting, and Mars orbit insertion (MOI).



\*\*Important:\*\* This is simulated mission data generated by GMAT. It is not actual MAVEN spacecraft telemetry or observational flight data.



\## 2. Dataset Files



| File | Description |

|---|---|

| `MAVEN\_MarsOrbit.csv` | CSV version of the simulated spacecraft trajectory |

| `MAVEN\_MarsOrbit.oem` | Original CCSDS Orbit Ephemeris Message (OEM) output generated by GMAT |

\## 4. CSV Data Structure



The CSV file contains seven columns.



| Column | Description | Unit |

|---|---|---|

| `Epoch\_UTC` | Date and time of the spacecraft state | UTC |

| `X\_km` | X position in the reference frame | km |

| `Y\_km` | Y position in the reference frame | km |

| `Z\_km` | Z position in the reference frame | km |

| `VX\_km\_per\_s` | X velocity component | km/s |

| `VY\_km\_per\_s` | Y velocity component | km/s |

| `VZ\_km\_per\_s` | Z velocity component | km/s |



\## 5. Coordinate System



The ephemeris was configured using the GMAT coordinate system `MarsFK5`:



\- Origin: Mars

\- Axes: MJ2000Eq

\- OEM reference frame: EME2000



The position and velocity values describe the spacecraft state relative to Mars in the configured reference frame.
