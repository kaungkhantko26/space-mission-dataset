# NASA/JPL mathematical references

Retrieved 2026-11-14 (Asia/Rangoon).

This folder contains local snapshots of two NASA Basics of Space Flight chapters and the NASA/JPL NAIF SPICE tutorial index. The NAIF page links to a complete PDF and ZIP tutorial collection; those large archives are recorded in `SOURCE_MANIFEST.json` and are downloaded separately if transfer bandwidth permits.

Sources:

- https://science.nasa.gov/learn/basics-of-space-flight/chapter3-2/
- https://science.nasa.gov/learn/basics-of-space-flight/chapter4-1/
- https://naif.jpl.nasa.gov/naif/tutorials.html
