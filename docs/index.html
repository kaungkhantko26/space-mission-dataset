Space Mission Dataset

Verified engineering data for the Space Mission Design Game: spacecraft, instruments, launch vehicle, budget, mass, power, communication and orbit. Every value traces to a retrieved source.

11,127 records · 22 collections · 7,657 launches · 532 launch vehicles · 1,578 components · 202 pads

start

  • datasets — download any collection as JSON, CSV or SQLite; training files
  • api — static JSON endpoints, no key, try it in the browser
  • equations — rocket equation, transfers, power, link budget, cost: formulas + calculators
  • explorer — browse, compare, mission-fit
  • guide — how to use everything

use it in 10 seconds

curl https://kaungkhantko26.github.io/space-mission-dataset/api/v1/planets/mars.json
curl https://kaungkhantko26.github.io/space-mission-dataset/api/v1/launch_vehicle_configs.json | jq '.records[0]'
import json, urllib.request
u = "https://kaungkhantko26.github.io/space-mission-dataset/api/v1/launch_pads.json"
pads = json.load(urllib.request.urlopen(u))["records"]
print(pads[0]["name"], pads[0]["latitude_deg"])
