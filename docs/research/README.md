# Research Data

This folder contains research manifests and documentation
for the NASA Hackathon Mars Mission Simulation project.

These files document potential AI development datasets
and Mars scientific reference datasets.

Raw datasets will be stored separately after verification.

In this research folder you can see two csv file.
From these two file, nasa_hackathon_data_research_2026-11-9 file has a priority column with A,B and C.
A means for AI development datasets
B means for Mars scientific reference datasets
C means for Game configuration datasets
