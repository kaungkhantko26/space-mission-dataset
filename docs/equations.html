equations

The formulas used by the dataset, with live calculators. Constants for bodies load from the verified API.

g0 = 9.80665 m/s² · c = 299 792 458 m/s · kB = 1.380649e-23 J/K · GM, radii, semi-major axes and irradiance come from planets / moons.

rocket orbit hohmann interplanetary power link light time mass & cost reliability

1 · rocket equation

dv = Isp * g0 * ln(m0 / mf)        mf = m0 * exp(-dv / (Isp*g0))
propellant = m0 - mf               burn time = (m0 - mf) * Isp * g0 / F
thrust-to-weight = F / (m0 * g0)



2 · circular orbit, escape, gravity


v_circ = sqrt(GM / r)     T = 2*pi*sqrt(r^3 / GM)     v_esc = sqrt(2*GM / r)     g = GM / r^2     r = R + altitude







3 · Hohmann transfer between circular orbits (same body)


a_t = (r1 + r2)/2
dv1 = sqrt(GM/r1) * (sqrt(2*r2/(r1+r2)) - 1)
dv2 = sqrt(GM/r2) * (1 - sqrt(2*r1/(r1+r2)))
time = pi * sqrt(a_t^3 / GM)







4 · Earth to planet (patched conics, circular coplanar)


a_t = (a1 + a2)/2          time = pi * sqrt(a_t^3 / GM_sun)
v_inf_dep = sqrt(GM_sun/a1) * (sqrt(2*a2/(a1+a2)) - 1)
dv_depart = sqrt(v_inf^2 + 2*GM_E/r_leo) - sqrt(GM_E/r_leo)          (from circular LEO)
dv_capture = sqrt(v_inf_arr^2 + 2*GM_T/r_p) - sqrt(GM_T/r_p)          (to circular orbit radius r_p)
synodic = 1 / |1/T1 - 1/T2|     phase angle = 180 - 360 * time / T2







5 · solar power and eclipse


S(d) = S_earth * (1 AU / d)^2       P = P_peak * S/S_earth * efficiency       needed = load * margin
eclipse time (circular, worst case) = T * asin(R / r) / pi          battery Wh = load * t_eclipse / DoD










6 · radio link budget (Friis)


FSPL (dB) = 20*log10(4*pi*d*f / c)
EIRP (dBW) = 10*log10(Pt) + Gt
noise (dBW) = 10*log10(kB * T * R)
margin (dB) = EIRP + Gr - FSPL - losses - noise - Eb/N0_required










7 · light time


one-way = d / c        round trip = 2d / c







8 · mass and cost budget


dry = sum(parts) * (1 + structure)       total = dry + propellant       need: total <= margin * launcher capacity
hardware cost = dry * USD_per_kg         total cost = hardware + launch price
USD_per_kg: low 149k / median 214k / high 428k  (ESTIMATE from NASA-stated development costs; launch price is real)









9 · launch reliability


rate = successes / launches
Wilson 95%: centre = (p + z^2/2n) / (1 + z^2/n),  half = z*sqrt(p(1-p)/n + z^2/4n^2) / (1 + z^2/n)
P(mission) = P(launch) * P(design checks pass)
