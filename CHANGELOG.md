# Changelog

## v2.4.0 — minimal monospace site
* Site restyled: monospace, black-and-white, light/dark, phone-friendly. New pages: `datasets.html` (download every collection and training file), `equations.html` (9 formula sections with live calculators using verified GM/radii/irradiance), interactive `api.html` (try any endpoint), `explorer.html` (the previous app). Generated by `tools/make_site.py`.

## v2.3.1 — third-party dataset cross-check
* Reviewed `minm01210-svg/Space-mission-`: all 55 numeric values that overlap the verified data agree (gravity constants, engines, launcher payloads, thrust); its 3 launch-site coordinates match Launch Library pads within 1.1 km. Report: `reports/external_crosscheck_minm01210.json`.
* New verified collection `launch_pads` (202 pads, coordinates, Earth-rotation launch boost) from the Launch Library records. Unverifiable items from that repository (atmosphere table, azimuth ranges, SLS core-stage estimate, templates) were not added; its files are not redistributed (no licence).

## v2.3.0 — training data, trajectories, reliability, budgets, user guide
* New verified collection `launch_history_all`: all 7,657 launches since 1957 (7,100 success / 523 failure / 34 partial) from Launch Library 2; Kaggle *All Space Missions* used only as a cross-check (97.6% agreement).
* `training/`: fact Q&A, physics examples, mission-design set (compatibility, success/failure reasons, per-component budget estimates), Earth→Moon/planet trajectories, launch reliability tables, AI-image prompt CSV.
* Budgets: launch prices are real; hardware cost is an estimate anchored to NASA-stated development costs ($149k-$428k/kg).
* New `USER_GUIDE.md` and site page `guide.html`.

## v2.2.0 — game-scoped dataset
* Scope check against the Space Mission Design Game brief (spacecraft, instruments, launch vehicle, budget, mass, power, communication, orbit). Removed data the game does not use: asteroids/dwarf planets, JPL NHATS (7,185) and NEO (1,265) lists, NASA facilities (485), 450 moon-element rows for non-game moons, and irrelevant SoA tables (3D printing, software, tracking, deorbit…). 12,830 → 3,250 records.
* Added from real sources: NSSDC fact-sheet values on planets/moons (solar irradiance, J2, day length…), instrument mass/power and mission cost statements parsed from NASA text with the source sentence kept.
* New `GAME_DATA_GUIDE.md` mapping each game mechanic to collections and formulas, with honest gaps; examples rewritten for the game; 64 validation checks, 22 backend checks.

## v2.1.0 — real data for the gaps
* **New verified collections:** NASA SoA small-spacecraft components (1,724 rows), Launch Library 2 launcher configurations (532) and SpaceX launch record (743), NASA NSSDC missions (39) and instruments (181), NSSDC atmospheres (10), NIST fluid properties (6).
* Source authority labels (`vendor-reported`, `aggregator`); 77 strict validation checks (every published value re-found in the raw source pages, no personal data, NIST physics sanity checks); 23 backend checks.
* Cross-check: the user-supplied SpaceX table agrees with Launch Library on 57/57 dates and 56/57 outcomes.
* New site tabs: Launchers, Components, Missions & instruments; Mission fit now also rates Launch Library vehicles.

## v2.0.0 — strict mode: verified data only
* **Public dataset is now `verified/`**; everything exposed (API, CSV/SQLite, backend, website) is verified. Removed from public output: instruments, components, propellants, atmospheres, ground stations, unverified vehicle/engine fields, mission masses/costs, the user-supplied SpaceX table, and the estimated/fictional optimizer.
* **Real datasets ingested directly:** JPL NHATS (7,185 targets), JPL SBDB NEOs with measured diameter (1,265), JPL satellite mean elements (461), official NASA Facilities (485, no contact data); user NASA facilities file cross-checked (485/485 agree).
* New: `tools/make_verified.py`, `tools/validate_verified.py` (51 checks re-reading raw files), strict local backend (NHATS search, Hohmann, light time), new website tabs (asteroid targets, facilities).
* `space-mission-research/` is now **staging only**; the synthetic optimizer moved to `labs/`.


## v1.0.0 — hackathon release
* **Data:** 25 celestial bodies, 24 engines/thrusters, 16 launch vehicles, stages/boosters, 23 component classes, 16 instruments, 14 historical missions, 8 ground stations, 80 constraints; user-supplied SpaceX launch table (2010-2018) and 485 NASA facilities.
* **Verification against retrieved sources** (JPL SSD/SBDB, NASA NSSDC + mission catalog, NASA SLS page, Apollo 11 press kit, NTRS papers, ULA, ESA): 32 records verified; 29 wrong/outdated recalled values replaced; 86 launch/mission field checks + 217 celestial field checks recorded with source text and file hashes.
* **Analysis & optimization:** Δv, power, communications, mass accounting; exact optimizer (3 scenarios × 9 objectives), Pareto fronts, sensitivity, Monte Carlo, solver benchmarks; vectorized exact solver.
* **Backend & access:** static JSON API (`docs/api/v1`), local backend `tools/serve_api.py`, CSV + SQLite exports, JS and Python clients, OpenAPI spec.
* **Web explorer:** explorer, compare with winners, mission fit, calculators, optimizer with balance controls, Monte Carlo simulator with suggestions, launch & facilities, API tab, benchmarks, quality.
* **Quality:** 82 automated validation checks; JS↔Python optimizer parity; backend smoke test; CI workflow.
* **Known gaps:** Falcon/Starship/Electron/most engines, spacecraft components, instruments and mission masses/costs are unverified; optimizer catalog is estimated/fictional; SpaceX table ends June 2018.
