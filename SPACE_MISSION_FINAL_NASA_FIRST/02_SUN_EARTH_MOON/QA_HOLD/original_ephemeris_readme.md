# Earth–Moon–Sun ephemeris package

Prepared for the general-purpose 2026–2036 Earth–Moon ephemeris task.

## Files currently prepared

- `processed\ephemeris\earth_state_vectors.csv`
- `processed\ephemeris\moon_state_vectors.csv`
- `processed\ephemeris\sun_state_vectors.csv`
- `raw\spice_extraction\earth_states_raw.txt`
- `raw\spice_extraction\moon_states_raw.txt`
- `raw\spice_extraction\sun_states_raw.txt`

These CSVs were generated by the NAIF CSPICE N0067 `STATES` reader from the official DE440S SPK. They contain 4,018 daily epochs inclusive of 2026-01-01 and 2037-01-01, with the observer at solar-system-barycenter (NAIF ID 0), J2000 frame, geometric corrections (`NONE`), kilometres and kilometres/second.

## Official kernels

The existing verified copies are retained under `raw\naif\`:

- DE440S: https://naif.jpl.nasa.gov/pub/naif/generic_kernels/spk/planets/de440s.bsp
- Leap seconds: https://naif.jpl.nasa.gov/pub/naif/generic_kernels/lsk/latest_leapseconds.tls
- Planetary constants: https://naif.jpl.nasa.gov/pub/naif/generic_kernels/pck/pck00011.tpc

DE440S was read successfully by NAIF `brief` (Toolkit N0067); its coverage is 1849-12-26 through 2150-01-22 ET. SHA-256 and byte sizes are recorded in `validation\ephemeris_validation_report.md`.

## Horizons status

The requested Horizons configuration is documented, but the raw Horizons responses and a direct Horizons-vs-DE440S cross-check are not claimed complete in this package until each response is saved and parsed. The Horizons API response observed during preparation reported DE441 and an `Ecliptic of J2000.0` frame header; therefore it must not be silently substituted for the requested DE440S/J2000-compatible validation.
