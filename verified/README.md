# verified/ — strict-mode dataset (generated)
STRICT MODE: this dataset contains only values that were compared with, or ingested directly from, retrieved authoritative sources (JPL SSD/SBDB/NHATS, NASA NSSDC, NASA SLS page, Apollo 11 press kit, NTRS papers, ULA, ESA, data.nasa.gov). Unverified, estimated and fictional values (optimizer catalog, costs, instruments, spacecraft components, Falcon/Starship/Electron and most engine specs, user-supplied SpaceX table) were removed. Derived values are computed only from verified inputs and are labelled derived.
